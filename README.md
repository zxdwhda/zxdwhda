### 🛠️ 一些开源与自用工具

- **[Datawhale · Coze AI Assistant](https://github.com/datawhalechina/coze-ai-assistant)** — 一起参与维护的开源课程，围绕 Coze 拆解了不少实用工作流与实操案例
- **[haoyuan-skills](https://github.com/zxdwhda/haoyuan-skills)** — 个人 AI Skills 集合，收录日常在用的技能与维护记录
- **[feishu-mcp](https://github.com/zxdwhda/feishu-mcp)** — 自托管飞书 MCP 服务，支持 OAuth 与阿里云函数计算部署
- **[baidu-drive-skill](https://github.com/zxdwhda/baidu-drive-skill)** — 第三方百度网盘 Claude Code Skill；纯 TS 单文件零外部依赖，上传下载搜索分享都能干，删除带防手滑保护
- **[agent-trace](https://github.com/zxdwhda/agent-trace)** — 把 Kimi Code CLI、Claude Code 的会话转成结构化 Trace，方便回看和统计
- **[consistent-timezone](https://github.com/zxdwhda/consistent-timezone)** — 自用的 Chrome 扩展，在工具栏看世界时钟，并按站点保持时区与 locale 表现一致
